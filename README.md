Fitness Tracker
===============

A full-stack fitness and health tracking web app.

Features
--------
- User registration and authentication
- JWT-based authentication
- Password reset via email
- Health tracking
- Activity tracking
- Running, walking, cycling, and weightlifting logs
- Calendar-based activity history
- Data graphs
- SQLite database

Technologies
------------
- Python
- FastAPI
- Pydantic
- SQLite
- JavaScript
- HTML/CSS
- Git/GitHub

Architecture
------------
- web/       HTTP/FastAPI routes
- service/   Business logic
- data/      Database operations
- models/    Data models
